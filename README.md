# Library Management System

A simple Java console-based Library Management System.

## Features

* Admin login
* Register new books
* Update book quantity
* View books borrowed by students
* Student registration and login
* View available books
* Borrow books
* Return books
* Pagination for books

## Technologies Used

* Java
* ArrayList
* Scanner
* Object-Oriented Programming

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Rohit16556/Library-Management-Java.git
```

### 2. Open the project folder

```bash
cd Library-Management-Java
```

### 3. Compile the Java files

```bash
javac Book.java Student.java LibraryApp.java
```

### 4. Run the application

```bash
java LibraryApp
```

## Requirements

* Java JDK installed on your computer.
